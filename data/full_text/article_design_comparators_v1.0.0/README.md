# Article-design comparator full texts v1.0.0

This snapshot contains the two full-text comparator articles used to deepen the
review-structure analysis. Both PDFs and structured XML versions were acquired
from legal publisher or repository endpoints on 2026-08-16.

The files under `files/` are intentionally gitignored. `manifest.json` records
their local paths, source pages, licenses, byte sizes, page counts, and SHA-256
hashes. The hashes allow the analysis to be reproduced against the exact local
documents without committing article content to the repository.

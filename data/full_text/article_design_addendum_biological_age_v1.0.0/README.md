# Biological-age comparator addendum v1.0.0

This snapshot contains the complete NIH author-manuscript text used to analyze
Rutledge, Oh, and Wyss-Coray, *Measuring biological age using omics data*.

The full text was acquired from PMC and NCBI BioC endpoints on 2026-08-16 in
HTML, BioC XML, and BioC JSON formats. The source files under `files/` are
intentionally gitignored. `manifest.json` records their provenance, sizes, and
SHA-256 hashes.

PMC identifies the record as an NIH author manuscript and does not declare an
open-content license for it. The local text is used only as a research source;
article content is not committed to this repository.

# CMACM v1.0.2 linearization-contract preflight

The Codex strict schema was accepted and Terra generated one CMACM record for
an unseen report. The semantic gate rejected it because the v1.0.2 contract
incorrectly required every linearization to contain all Foundation members.
WHO linearizations are purpose-specific constrained views, so this was a
contract defect rather than a scientific extraction result.

CMACM v1.0.3 adds explicit membership rules for every linearization. The UCP1
report observed in this preflight is excluded from the prospective v1.0.3 sample
and retained here only as a technical audit record.

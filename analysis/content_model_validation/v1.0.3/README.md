# CMACM v1.0.3 Development Validation

This is a prospective 15-report, three-repeat Terra development run of the
WHO-based Causal Multi-omics Aging Content Model. The sample was disjoint from
all earlier causal-extraction, codebook and transfer-check samples.

The run is rejected as a production extraction contract. Exact agreement was
1/15 for the complete Foundation structure, 8/15 for workflow count, 5/15 for
causal-link count, and 10/15 for design-family set. The full diagnosis is in
`diagnostic.md`.

The result does not reject WHO Content Model as primary methodology. It rejects
the v1.0.3 operational individuation rules. The next contract must define
workflow identity by procedure and study context, link identity by exposure
family and normalized outcome domain, and cite deterministic evidence atom IDs
instead of model-generated free quotations. A different held-out sample must
test that amended contract.

No eligibility, PRISMA, or synthesis count changed.

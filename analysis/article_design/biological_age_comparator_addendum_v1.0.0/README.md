# Biological-age comparator addendum v1.0.0

This addendum records an independent full-text analysis of:

Rutledge J, Oh H, Wyss-Coray T. *Measuring biological age using omics data*.
Nature Reviews Genetics. 2022;23(12):715-727.
DOI: `10.1038/s41576-022-00511-7`; PMCID: `PMC10048602`.

The source is a narrative review, not a systematic review. It was analyzed to
refine the biological-aging measurement taxonomy of the planned systematic
evidence map, not to supply a PRISMA method or causal appraisal framework.

## Decision

Retain the primary hierarchy:

`causal discovery -> causal-effect evidence -> independent validation`

Add an orthogonal measurement taxonomy:

`aging construct x temporal target x biological scale x clock role x validation target`

Prediction, age-gap association, longitudinal measurement, and intervention
responsiveness do not become causal evidence without an appropriate causal
design.

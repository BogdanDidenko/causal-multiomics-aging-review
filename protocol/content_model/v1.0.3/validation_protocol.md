# Prospective Validation Protocol

The initial validation uses a frozen, unseen, stratified 15-report sample drawn
from the 357 canonical reports after report-version collapse. The sample is
disjoint from all prior causal-extraction, codebook, and transfer-check samples.

Three isolated GPT-5.6 Terra Medium runs receive the same complete Docling
Markdown and CMACM v1.0.3 contract. No section selection, splitting,
truncation, or size-based exclusion is allowed. Each run produces Foundation
entities, postcoordinated axes, source evidence and declared linearizations.

Primary stability outcomes are exact agreement for:

- whether a report has any `CausalWorkflow`;
- workflow design-family set;
- workflow count under the individuation rule;
- causal-link count under the link individuation rule;
- each linearization's declared counting unit.

Secondary audit outcomes are source-evidence quotation validity, referential
integrity, logical-condition completeness for effect-identification links, and
correct separation of validation from workflows/links.

This feasibility run evaluates representational stability and auditability. It
does not estimate screening accuracy, change eligibility, or claim that the
taxonomy is uniquely correct.

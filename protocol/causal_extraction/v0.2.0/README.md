# LEGACY: rejected causal-extraction pilot

Status: **legacy, rejected, frozen, not production-approved**.

This directory preserves the `v0.2.0` causal-extraction codebook and schema as
instrument-development history. They were rejected before passing prespecified
semantic-validity and stability gates against expert gold labels. Do not use
them for current extraction, Docling Graph construction, scientific synthesis,
causal-level assignment, or gold-standard annotation.

Permitted uses are limited to methodological postmortem and documentation of
the rejected pilot. The original semantic files remain unchanged so the audit
trail is reproducible. Their original hashes are recorded in `lifecycle.json`.

There is currently no active replacement codebook. The proposed hierarchical
replacement will begin at `v0.3.0` only after prospective development and
validation.

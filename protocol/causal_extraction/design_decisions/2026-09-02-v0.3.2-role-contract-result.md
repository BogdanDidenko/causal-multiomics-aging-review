# v0.3.2 role-contract result

Date: 2026-09-02

## Decision

Reject `v0.3.2` for production. Splitting the compound classification into
five short roles did not pass the frozen exact-agreement gate and did not
improve the main stability endpoints. Preserve the full negative result as an
ablation in the methods audit.

Retain `v0.3.1` as the best observed fixed-candidate qualification contract on
the development set. Validate that narrow endpoint on an independent sample
before using it beyond development. Do not use unstable detailed fields or
Levels from either version in scientific synthesis.

## Result

- Valid calls: 300/300; no terminal technical failures.
- Five-repeat exact candidate qualification: 40/45 (88.9%).
- Five-repeat exact derived Level: 22/28 (78.6%).
- Five-repeat exact complete candidate record: 14/45 (31.1%).
- Five-repeat exact complete report: 0/12.
- Include sensitivity against the analyst draft: 95.0%.
- Exclude specificity against the analyst draft: 97.6%.

The reference is an AI-assisted analyst draft pending human verification, so
the last two values are development diagnostics rather than accuracy claims.

## Role-level result

| Role | Five-repeat exact candidates |
|---|---:|
| Eligibility criteria | 36/45 (80.0%) |
| Design identity | 24/28 (85.7%) |
| Review context | 22/28 (78.6%) |
| Effect appraisal | 12/28 (42.9%) |
| Validation | 15/28 (53.6%) |

At field level, `causal_basis` remained exact for 28/28 candidates, while
`result_status` and `validation_strength` were each exact for 15/28. The
eligibility decline was driven mainly by `distinct_design_unit` (38/45 exact),
showing that atomizing a holistic candidate decision exposed an underdefined
boundary rather than removing it.

## Interpretation

The `v0.3.1` result showed that Terra can reproducibly decide whether a fixed,
well-described candidate qualifies. The `v0.3.2` result shows that simply
asking the same semantic questions in smaller prompts is insufficient. Fields
such as candidate-level result status, same-link validation, and design-unit
identity need explicit operational decision tables and independent accuracy
labels. Further tuning on these 12 reports would risk overfitting.

The next experiment therefore moves to a disjoint validation set. It tests the
stable `v0.3.1` qualification endpoint and a separately declared candidate
discovery procedure. Detailed characterization remains a later instrument.

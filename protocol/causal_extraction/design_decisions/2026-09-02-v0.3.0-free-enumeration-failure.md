# v0.3.0 free-enumeration failure and candidate-boundary ablation

Date: 2026-09-02

## Decision

Reject `v0.3.0` for production causal extraction. Preserve its frozen protocol,
60 model calls, normalized outputs, and summary as instrument-development
history. Do not process the remaining 89 reports with this configuration.

Run a separately versioned, prospective one-factor ablation on the same 12
development reports. The ablation fixes candidate-analysis boundaries and
canonical evidence anchors before Terra classification. Model, reasoning
effort, source reports, five-repeat schedule, codebook definitions, and closed
classification fields remain unchanged.

## Observed result

- Valid terminal calls: 60/60.
- First-attempt schema failures: 2/60; both resolved by the frozen one-retry
  policy.
- Exact report agreement at three repeats: 1/12 (8.3%).
- Exact report agreement at five repeats: 1/12 (8.3%).
- Exact five-repeat analysis-anchor-set agreement: 1/12 (8.3%).
- Stable five-repeat analysis count: 7/12 reports.
- Stable source-sufficiency status: 12/12 reports.
- Stable conceptual reference-analysis membership: 8/12 reports.
- Mean evidence-overlap alignment to the analyst draft: recall 90.4%, precision
  80.0%. These are development diagnostics, not expert-gold accuracy estimates.

## Failure interpretation

The free-enumeration task combines three operations in one response:

1. discover all causal-analysis candidates;
2. decide the boundary of each design-level unit and choose one exact method
   and result anchor;
3. classify all scientific fields and validation evidence.

The complete deterministic source packet and evidence-ID interface worked:
all calls produced grounded, schema-valid terminal outputs, and source status
was unanimous. Instability arose mainly from equivalent anchor choices,
splitting or merging design units, optional validation anchors, and downstream
Level changes. Exact evidence IDs therefore confound semantic disagreement
with citation-choice disagreement when the model selects both freely.

## Prospective ablation

The next experiment isolates candidate classification:

- derive an opaque candidate scaffold from the reference inventory frozen
  before the `v0.3.0` model run;
- include both qualifying analyses and rejected boundary candidates;
- expose candidate labels and exact candidate evidence, but never the analyst
  include/exclude label, reason code, note, or reference class;
- assign canonical anchors deterministically outside the model;
- ask Terra to classify every fixed candidate using the same scientific
  codebook and closed fields;
- compare three-repeat and five-repeat exact agreement with `v0.3.0`.

This ablation measures classification stability conditional on candidate
discovery. It does not estimate automated discovery recall and cannot by itself
authorize production extraction. If it passes, candidate discovery becomes a
separate measured stage; if it fails, the next ablation must split compound
classification fields into shorter role contracts.

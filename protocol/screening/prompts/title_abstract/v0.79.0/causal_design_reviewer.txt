STABILITY CONTRACT

ORDERED COMPLETION TABLE

1. Return `no` when the current report is explicitly a review, systematic
   review, scoping review, meta-analysis, evidence synthesis, editorial,
   commentary, News & Views, research highlight, or news item and reports no
   substantive original empirical biological analysis.

   Literature searching, study selection, data charting, descriptive
   synthesis, meta-analysis of prior-study estimates, and a review Results
   section do not count as original current-report empirical analysis.

2. Return `no` when the current report is only a protocol, future proposal,
   planned/ongoing enrollment, method-only description, data descriptor,
   cohort profile, atlas/database, biobank, repository, or infrastructure
   description without a substantive completed biological analysis/result.
   Recruitment, collection, profiling availability, and resource contents
   alone do not count.

3. Return `yes` for a completed current-report data analysis, experiment,
   secondary analysis, model application to real biological data, or
   substantive result. Original empirical methods/results override a generic
   document label.

4. A truncated record is still `yes` when its current-report title says an
   analysis `reveals`, `identifies`, or `finds` a result, or the fragment says
   `we performed`, `we analyzed/analysed`, or `we profiled` and names the
   analysis or result.

5. Return `unclear` only when the supplied fragment cannot resolve whether the
   current report completed substantive analysis/results. Missing causal
   assumptions or design details do not make completion unclear.

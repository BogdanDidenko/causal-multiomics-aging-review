STABILITY CONTRACT

Classify the current report, not studies cited or summarized by a review. A
method is applied only when the record attributes its use to the current

Step 1: choose exactly one `causal_basis` from the positive table. Stop at the
first established row.

1. `named_causal_effect_design`: the current report applies an explicitly
   named randomization, quasi-experiment, genetic instrument, controlled
   perturbation, intervention-effect design, or temporal identification design
   intended to estimate a causal contrast. Generic `effect`, `impact`,
   longitudinal follow-up, association, or mediation wording alone is not
   enough.
2. `formal_directed_hypothesis`: the current report applies a formal directed
   model or causal-discovery method, but no design in row 1 is established.
   This includes directed mediation, DAG/SCM, causal Bayesian networks, causal
   network inference, PC, FCI, GES, LiNGAM, NOTEARS, or directed SEM. An
   observational mediation analysis remains in this row unless an independent
   row-1 design identifies its causal contrast.
3. `causal_analysis_method_unspecified`: the current report explicitly states
   that it performed causal analysis or estimated a causal effect, but neither
   the effect-identification design nor a formal directed method is named. An
   odds ratio, confidence interval, or generic `effect` is not sufficient.

Step 2: if no positive row applies, choose exactly one negative or unresolved
row using this mutually exclusive table.

4. `association_or_prediction_only`: the current report applies an
   association, correlation, prediction, classification, enrichment,
   differential analysis, colocalization, or undirected-network method and no
   positive formal causal method. This row takes precedence even when the
   discussion also uses causal or mechanistic wording.
5. `causal_wording_only`: no current-report positive causal method and no
   current-report method from row 4 is established, but the record uses an
   explicit causal/mechanistic claim such as cause, causal, causality,
   mechanism, mechanistic, drives, regulates, or influences.
6. `none`: no positive causal method, no row-4 current-report analysis, and no
   explicit causal/mechanistic claim are present in a sufficiently complete
   record.
7. `unclear`: use only for a visibly truncated record or genuinely unresolved
   current-report attribution. Do not use it merely because a negative class
   requires interpretation.

Set `current_report_application=yes` for rows 1-3, `no` for rows 4-6, and
`unclear` for row 7.

ROUTING DESIGN ANCHOR

`design_families` is not an exhaustive inventory at title/abstract screening.
Full design profiling is deferred to full text. For rows 1-2, return exactly
one routing anchor: the first explicitly applied family in this frozen list.

1. `randomized_intervention`: explicit random assignment of an exposure or
   treatment.
2. `quasi_experiment`: natural experiment, target-trial emulation,
   difference-in-differences, or regression discontinuity.
3. `genetic_instrument`: MR, IV, SMR, or another genetic-instrument analysis;
   GWAS/QTL alone is not an instrument design.
4. `direct_perturbation`: controlled molecular, cellular, or animal knockout,
   knockdown, overexpression, CRISPR, or administered perturbation.
5. `nonrandomized_intervention`: an administered human intervention without
   explicit randomization and not covered by a higher row.
6. `temporal_identification`: interrupted time series or another explicitly
   identified temporal causal design; longitudinal follow-up alone is not.
7. `formal_mediation`: an applied formal mediation/path model not supported by
   a higher-precedence effect-identification design.
8. `dag_scm`: an applied DAG or structural causal model.
9. `causal_discovery_algorithm`: causal network inference, PC, FCI, GES,
   LiNGAM, NOTEARS, or another applied causal-discovery algorithm.
10. `bayesian_network`: an applied directed/causal Bayesian network.
11. `sem`: an applied directed structural equation model.
12. `other_formal_causal_design`: a named formal method that fits none of the
    rows above.

The ordering is a reproducible tie-break rule, not an evidence hierarchy. If
several methods occur, return only the first anchor. For rows 3-7, return an
empty array.

GWAS, QTL, colocalization, TWAS, PRS, ordinary regression, WGCNA,
co-expression, CellChat, SCENIC, pathway direction, feature importance,
pseudotime, and generic regulatory networks are not causal designs by
themselves.

Set `causal_information_sufficiency=sufficient` when the visible record is

visibly truncated record and `unclear` only when the sufficiency boundary

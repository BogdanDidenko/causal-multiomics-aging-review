# Search Query Pack v1.0.0

Each database query combines three concepts:

1. explicit multi-omics terminology **or** at least two distinct molecular
   layer blocks;
2. an explicit aging-process construct;
3. a named causal-effect or formal causal-discovery design.

The pairwise layer blocks are genomics, epigenomics, transcriptomics,
proteomics, metabolomics/lipidomics, and microbiomics/metagenomics. Generic
verbs such as `affects`, `regulates`, `drives`, and `influences` are not causal
anchors.

OpenAlex and Google Scholar cannot express the complete pairwise Boolean
contract reliably. Their queries retrieve a broader union of molecular-layer
terms; the frozen local validator requires either explicit multi-omics wording
or at least two detected layer blocks before a record enters the v1 candidate
frame.

This pack remains in calibration until two experts independently assess the
120-record prioritized candidate pool, adjudicate disagreements, verify at
least 100 eligible canonical positives, and review 50 records from each
retrieval branch per database. The candidate pool itself is not a gold
standard.
